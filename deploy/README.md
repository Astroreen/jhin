# Запуск Jhin

## Запуск

```bash
java -jar jhin.jar
```

Backend слушает `0.0.0.0:8443` по умолчанию (TLS, самоподписанный сертификат генерируется при первом старте). Конфиг — `application.yml` рядом с jar или через переменные окружения (`JHIN_HOME` — каталог данных, по умолчанию `~/.jhin`).

## Рестарт-луп

Для `POST /admin/reload` (graceful restart) запускать под wrapper:

```bash
./run.sh jhin.jar
```

Скрипт перезапускает процесс через 1 секунду после выхода; SSE-клиенты реконнектятся сами (resume по `fromSeq`).
