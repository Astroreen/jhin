# T82 golden review (pixel/ink-map probes — OPTION 1)

Review method: per-file pixel probes (pure-python PNG decode: zlib inflate +
PNG unfilter, no image display). The Read tool image path is unreliable in this
environment (scrambled PNG rendering) and was NOT used; bash/python pixel
probes are ground truth. The orchestrator independently re-analyzed the 5
state goldens with a pure-python pixel probe and confirmed the numbers below
exactly (state-offline ink only in y=0..227; state-empty / state-version-gate
span to y≈680).

Probe: /tmp/opencode/t82_probe.py (committed content mirrored in this file's
stat lines). Ink pixel = per-channel delta > 16 from the modal corner
background. Stats per file: dimensions, ink-row bbox (y), ink bbox (x),
interior max empty-gap (rows with zero ink between first and last ink row),
quarter-band ink densities (q0..q3 top to bottom), overflow-stripe yellow
pixel count (high-R/high-G/low-B heuristic) and mid-density row count.

FLAG criteria applied: fully blank; ink confined suspiciously (tiny bbox in a
full-surface golden without a design explanation); huge interior empty gaps
suggesting clipped/vanished content; yellow-black overflow stripes.

Global note: every golden carries the Flutter debug banner at the top-right
(corner triangle, e.g. x=743..799 y=0..56 on 800x1200 surfaces, reddish
(162,64,65) over the surface). Provenance proven earlier with a bare
MaterialApp scratch — test-harness artifact, not a product bug; banner ink
counts toward bbox_y=0 and is discounted in the verdicts below.

## Summary

Sampled: 13 (3 named screen goldens, 5 gallery fixtures, 5 boot state goldens).
OK: 13. FLAGGED: 0.
- No fully blank golden (every file has content ink beyond the debug banner).
- No suspicious confinement: every small bbox is explained by a natural-height
  fixture (chip/menu/table/markdown/form, thread-row) or by a top-start
  designed layout (shell slots, fallback card/container art) or by Center
  (empty, version-gate).
- No overflow stripes anywhere (yellow=0 in all 13; no alternating high-density
  stripe rows).
- The 3 top-aligned state goldens (error/offline/loading) are top-aligned by
  the designed widget layout — code citations above; no doc prescribes
  centering, so no fix needed and no golden refresh required.
