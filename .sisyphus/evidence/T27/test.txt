=== acceptance criterion ===
A used or expired code is refused; a revoked device is refused.
- used code   -> 410 code_used    (EnrollmentServiceTest.redeemTwiceRefusesWithCodeUsed)
- expired     -> 410 code_expired (EnrollmentServiceTest.redeemAfterTtlRefusesWithCodeExpired,
                                   MutableClock injected, advanced past the 10 min TTL)
- revoked dev -> 403 forbidden    (DeviceServiceTest.revokeRejectsTokenWithForbidden)
Enrollment code: 128-bit SecureRandom, unpadded Base32 display form returned
once, only SHA-256(code) stored in jhin_security_enrollment_codes.code_sha256.
Device token: 256-bit SecureRandom, hex display form returned once, only
SHA-256(token) stored in jhin_security_devices.token_sha256 (UNIQUE).
Single use: validity check + used_at mark run in one serialized write unit.
SecurityAttributes.PRINCIPAL = "jhin.security.principal"; Principal exposes
public accountId() for the reflective cross-plugin contract.
No passwords, no JWT, no OAuth.
