=== harness note ===
Self-contained test harness under src/test (TestDbAccess + RecordingStreamRegistry):
real SQLite file per test behind the DbAccess contract; reads on the caller
thread against fresh connections, writes serialized on one executor thread
(kernel WriteQueue semantics); unchecked exceptions propagate unchanged,
SQLException wrapped in PluginException (DbAccessImpl semantics). Chosen over
wiring kernel Database/WriteQueue so plugin tests depend only on the SDK — the
artifact plugins actually see at runtime — and need no kernel coupling in
plugins/sessions/build.gradle.

=== build.gradle change (documented) ===
plugins/sessions/build.gradle gained a dependencies block:
  testImplementation 'org.xerial:sqlite-jdbc:<same version as kernel/build.gradle>'
  testRuntimeOnly 'org.junit.platform:junit-platform-launcher:1.11.4'
(test-only: sqlite stays out of the runtimeClasspath, hence out of the jar;
launcher needed by Gradle 9 test execution, matching jupiter 5.11.4 from
gradle/plugin-conventions.gradle)
