T71 negative probes
===================

1. re-running v2 on a v2 database is a no-op
   - first migrate(all()) applied versions [1, 2] and recorded them in _jhin_plugin_schema
   - second migrate(all()) applied nothing: versions still [1, 2], schema unchanged
   OK: migration idempotence holds; the version table is the guard

2. raw v2 SQL re-applied outside the bookkeeper fails
   - executing the v2 script again directly: SQLiteException: [SQLITE_ERROR] SQL error or missing database (duplicate column name: pinned)
   OK: the SQL itself is not idempotent; only the bookkeeper makes re-runs safe

3. patch with pinned on an unknown session throws
   - store.patch("missing-session", Patch(pinned=true, ...)) threw PluginException: session missing-session not found
   OK: unknown-session patch fails loudly
