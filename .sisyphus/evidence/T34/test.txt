--- design notes ---
one ToolProvider (private named BuiltinToolsProvider inside ToolsPlugin) publishes the
whole set; ToolInvoker resolves it live via services().findAll(ToolProvider.class).
structured card family documented on FileToolSupport; built only by
FileToolSupport.Structured (card/image), asserted by assertCard() in ToolsSuiteTest.
error contract: every failure returns ToolResult.error with a stable message; tools
catch ToolException (arg validation + sandbox escapes) - the 5 failure assertions all
observe returned errors, never throws.
edit-diff uses the same unique-match rule as edit (ambiguous -> same stable error) so a
previewed edit always matches what edit would do.
bash runs 'sh -c' explicitly (zero external binaries in tools; zt-exec is bundled
library code); powershell runs 'powershell -NoProfile -NonInteractive -Command' and is
registered only when os.name starts with "Windows".
