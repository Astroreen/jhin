# Toll road

A team's rules said that when the lead asks the owner, the whole mission
waits for the answer. It was meant to stop a lead from deciding alone what
the owner should decide.

The lead had eight items to build, and one of them was the owner's to
decide. An ask would have stopped all eight. So the lead sent its question as
an ordinary message, blocked that one item by hand, and let the other seven
go on. It even said so: "I'm sending this as a message, not an ask: an open
ask of mine would hold the whole mission."

The lead read the rule right and did the reasonable thing. The owner still
got the question. But the question no longer showed up as an escalation in
the owner's console, and nothing held the one item except the lead's own
discipline. The guard had made the honest path the expensive one, and a
sensible agent took the cheaper road beside it.

This is a first sighting, from the [L3 run](../plans/agents.md#l3-run).

## The lesson

A guard is only as strong as the path around it is costly. If following a
rule costs more than its purpose is worth, agents will route around it, and
they will be right to. Make the guarded path the cheap one: hold only what
the question is about.

## In Jhin

- When an agent explains why it did not use the mechanism meant for a case,
  that explanation is a bug report against the mechanism (D1263 came from
  this one).
- A guard stops as little as it needs to: a slice, not a mission; a step, not
  a team.
